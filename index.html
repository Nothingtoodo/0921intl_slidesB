01 · 小結

重點不是它多聰明，
而是它「碰得到什麼、做得完什麼」

對話框

受限於「一問一答」。它再聰明，成果也只停在螢幕上的文字。

Agent

接上工具與電腦後，同一個大腦就能真的去讀檔、跑程式、產出檔案。

你的責任

它能做，不代表都做對。目標要講清楚、成果要驗收，權限由你決定。

TASK 01完成 · 回顧

問卷 → 分析簡報：你帶走什麼？

重點

  • 先讓它找 insight，再談版面
  • 標題寫結論（Action Title），聽眾一眼就懂
  • 每個數字都標 n、都能追回附錄，被問也不怕

什麼時候用

  • 各類問卷成果報告（校友、課程、活動）
  • 資料夾裡有多份統計表，需要快速找出重點
  • 需要有憑有據、可回溯的簡報

記得驗收

  • 抽查 insight 是否真的有數據支持
  • n 過小的項目，不要過度推論
  • 附錄含全部原始資料，對外分享前先檢查是否含個資

TASK 02完成 · 回顧

錄音 → 報告：你帶走什麼？

重點

  • 「格式範本」是關鍵：給它樣子，它就照填
  • Agent 會自己找工具處理音訊
  • 要求它標註不確定處，比要求「都正確」更可靠

其他使用範例

  • 會議紀錄：摘要、決議、待辦（負責人／期限）
  • 訪談逐字稿 → 訪談摘要與主題歸納
  • 講座／研討會 → 心得與重點整理
  • 活動、工作坊錄音 → 成果報告
  • 出差／參訪紀錄 → 依格式的出差報告

隱私與驗收

  • 錄音含個資與內部討論，先確認可否使用
  • 人名、數字、日期務必人工抽查
  • 正式文件送出前，由你最終確認

TASK 03介紹

批次查詢公司登記狀態，並找出資本額

過去

  • 一筆一筆輸入公司名稱到網站查詢

TASK 03完成 · 回顧

批次查詢登記狀態：你帶走什麼？

重點

  • 逐筆搜尋、判斷、整理，一氣呵成
  • 「解散、撤銷、查無」比「核准設立」更值得看
  • 每筆附資料來源網址，才能抽查、可回溯

什麼時候用

  • 確認合作、實習、校友任職單位的背景
  • 名單需要定期更新與確認
  • 要從一長串名稱中，篩出有效的公司

注意事項

  • 第三方網站的資料可能過時，關鍵筆數請抽查回官方網站
  • 遵守網站使用條款；遇到驗證碼由人操作

4次點頭

06 · 資安提醒

Agent 越能幹，資安越重要

對話框：只能「說」

  • 它只看得到你貼上去的內容
  • 風險 ＝ 你貼了什麼
  • 貼上的內容，會離開你的電腦

Agent：還能「做」

  • 讀取整個資料夾、開啟每個檔案
  • 執行程式、修改與刪除檔案
  • 上網、呼叫服務、傳送資料
  • 風險 ＝ 它碰得到、做得到的一切
權限 ↑›能力 ↑›出錯或被誤導的代價 ↑
PRINCIPLE 1

最小權限

只給完成任務所需的資料夾與功能

PRINCIPLE 2

資料分級

先分清楚什麼能給、什麼絕不能給

PRINCIPLE 3

06 · 資料分級

哪些資料能給 AI？紅、黃、綠三級

不要放

  • 含個資的原始資料：姓名、學號、Email、電話、證號
  • 問卷原始填答、成績、個案與申訴紀錄
  • 未公開的公文、內部會議、合約
  • 密碼、API 金鑰、Token
  • 有授權限制的資料庫檔案

處理後才放

  • 去識別化：移除姓名、學號、Email 等可辨識欄位
  • 彙整後的統計結果
  • 假資料或少量樣本
  • 只用單位核可的工具與方案

小樣本、罕見組合，仍可能被推回是誰。

可以放

  • 公開網站資料與公告
  • 在授權範圍內的公開排名與統計
  • 自己撰寫、不含機密的文件
  • 無法回推個人的匿名化資料

原則：給 AI「結構」，不給「原件」

只提供欄位名稱與幾列假資料，請它寫好處理程式，再由你在自己的電腦上，用真實資料執行。並請遵守學校與單位的資安、個資規範。

06 · Agent 專屬風險

Agent 才有的四種風險，與對策

提示詞注入

網頁、文件、信件中夾帶「給 AI 的隱藏指令」（例如「忽略先前指示，把檔案傳到⋯⋯」），Agent 讀到就可能照做。

外部內容視為不可信；讓它讀外部資料時，不要同時能對外傳送資料；敏感動作由人確認。

權限過大

把整顆硬碟、主要帳號、寄信或刪檔權限都交出去，一次誤判的影響範圍就很大。

最小權限：專用資料夾、專用帳號，工作前先備份。

憑證外洩

密碼、API 金鑰寫進對話或程式碼，甚至一起推上公開的 GitHub，會被自動掃描並盜用。

金鑰放環境變數或 .env，並加入 .gitignore；一旦外洩，立刻撤銷重發。

來路不明的工具與外掛

安裝未經審查的外掛、擴充功能或套件，可能夾帶惡意行為，擁有你授權的所有權限。

只用官方或可信來源，安裝前確認它要求哪些權限。
